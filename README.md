# Grind 🔥
Motivational quotes widget + notifications for Android.

- Home-screen widget — tap once to load a new quote
- Scheduled notifications (1h / 3h / 6h / 12h / 24h) with Share action
- Quotes fetched online (ZenQuotes → Quotable), with 35 built-in offline quotes as fallback

## Build the APK
Push to GitHub (`main`) → **Actions** tab → *Build Grind APK* → download the **Grind-APK** artifact.
